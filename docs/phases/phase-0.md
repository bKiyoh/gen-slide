# Phase 0 — Vue 3 + Three.js 描画基盤

**Codex向け実装依頼。** このファイルの作業だけを行い、Phase 1以降には進まないこと。

## 0. 着手前に読むもの

1. リポジトリルートの `AGENTS.md`
2. `docs/DESIGN.md`
3. `docs/SPECIFICATION.md`
4. この `docs/phases/phase-0.md`

既存リポジトリがある場合は、構成、依存、開発コマンド、Lint／テスト設定を確認してから実装する。新規の場合はVue 3 + Viteの最小構成とする。現在の仕様に不要なライブラリは導入しない。

## 1. 目的

Vue 3とThree.jsで**赤い長方形・青い平行四辺形を画面に描画し、数値パラメーターの変更で即時に表示を更新できること**を確認する。

本格的なアニメーションやエディタを作るPhaseではない。**GPU描画の初期化・形状生成・描画更新・後始末が追える最小実装**を作る。

## 2. 採用技術

- Vue 3（Composition API / `<script setup>`）
- Vite
- JavaScript + JSDoc（TypeScriptを追加しない）
- Three.jsの `WebGPURenderer` を第一候補にする

使うThree.jsのバージョンに対応する公式APIを確認し、非同期初期化の完了後に描画すること。`WebGPURenderer`がWebGL 2へフォールバックする場合、画面または開発者ツール上で**実際のバックエンドを区別**できるようにする。バックエンド判定APIが存在するか推測で実装しない。

## 3. 実装範囲

### 3.1 VueとCanvas

- Vueコンポーネントに描画先のコンテナを設置する。
- `onMounted`でThree.js描画処理を初期化し、`onUnmounted`で停止・解放する。
- VueコンポーネントにはScene/Camera/Geometry/Materialの低レベル処理を直接書かず、呼び出す側に限定する。
- パラメーター変更は最小限の入力UI（数値入力／スライダー等）で確認できればよい。

### 3.2 Three.jsの描画基盤

- Scene、OrthographicCamera、WebGPURendererを構築する。
- 論理キャンバスは1920×1080、左上原点、X右向き、Y下向き、16:9で扱う。
- 表示領域の縦横比が16:9でない場合は、**画面が欠けたり変形したりしないよう等比スケールで収める**（余白の扱いは明示）。
- Retina等の高DPI画面では描画解像度と論理座標を混同しない。
- リサイズ時に表示倍率とレンダラーサイズを更新する。
- WebGPUが使えない／初期化失敗した場合は、原因または利用不能の状態を表示する。自動フォールバックの扱いはThree.jsの実挙動に沿って実装する。

### 3.3 Rectangle / Parallelogram

- `BufferGeometry`を使い、**四角形は2つの三角形**で構成する。
- `Rectangle` と `Parallelogram` を描画する。
- 最低限のパラメーター：`width` / `height` / `skewX` / `x` / `y` / `rotation` / `color` / `opacity`。
- 値の単位は幅・高さ・座標が論理ピクセル、角度が度、opacityは0〜1。
- 平行四辺形は`skewX`を変更すると四辺形の傾斜が変わる。例えば、**上辺が下辺に対して `height * tan(skewX)` だけ水平移動する**と定義する場合は、頂点の座標と回転順序を明示する。
- 図形のピボットは中心を基本とする。変形順序をコメントか設計メモで示す。
- 無効な入力（幅0未満、NaN、過度な傾斜等）で描画が破綻しないよう検証する。

### 3.4 サンプル画面

次を同時に確認できるサンプルを用意する。

- **赤い長方形**
- **青い平行四辺形**
- 長方形の幅・高さ、平行四辺形の幅・高さ・傾斜を変更できる簡単な入力欄
- 値の更新がすぐ描画結果へ反映される
- 表示バックエンド（WebGPU／WebGL2／判定不能）と、失敗時の情報

可能なら位置・回転・色・不透明度も数値から変更できることを確認する。

## 4. コードの責務とファイル分割

完全なディレクトリを強制するものではない。既存構成があればその規約を優先し、少なくとも次を分離する。

| 責務 | 内容 |
|---|---|
| Shape Data | 位置・サイズ・色・傾斜等のプレーンなJSデータ |
| Shape Geometry | 入力値から4頂点と2三角形の形状を計算。可能ならThree.js依存なし |
| GeometryFactory | 頂点情報からThree.js `BufferGeometry`を生成 |
| Renderer | Scene/Camera/Rendererの作成、描画、更新、リサイズ、破棄 |
| Vue Sample | Canvasの設置、入力UI、値の受け渡しと状態表示 |

VueがThree.jsインスタンスを直接扱う設計にせず、Renderer側に描画更新の窓口を設ける。ただしPhase 0の規模で過剰なクラス階層・DIコンテナ・汎用イベントシステムを作らない。

## 5. テスト・品質

- 図形の頂点計算について、長方形と傾斜した平行四辺形の代表ケースを確認する。
- パラメーター変更前後の描画結果をブラウザ上で確認する。
- リサイズで論理座標が変化しないことを確認する。
- アンマウント時にイベントリスナー、描画ループ、Geometry/Material/Rendererを必要に応じて停止・解放する。
- 初期化中にアンマウントされた場合も例外や破棄漏れが生じないようにする。
- 既存Lint/テスト/ビルドがあれば実行する。実行できなければ理由を書く。

## 6. 実装しないもの

- ShapeGroup、Generator、Modifier、Overrides
- Animation / Keyframe / Stagger / Timeline
- Transition Editor本体とPresentation本体
- 保存（localStorage / JSON import/export）
- 3Dモデル、シェーダーによる特殊演出、動画出力
