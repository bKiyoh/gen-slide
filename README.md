# Generative Slide System

Vue 3 + Three.js の図形生成・描画サンプル。現在は **Phase 1** まで実装しています。

個別 Shape と ShapeGroup を混在させ、Linear / Grid 配置、Alternate / Linear Modifier、個別 Overrides を確認できます。赤・青の平行四辺形10個のうち3番目だけ白・X +40にし、生成数を減らして戻しても上書きを保持します。表示中の描画バックエンドと初期化エラーも画面に表示します。

画面上部の切り替えで、従来の **Phase 0 · 描画基盤**（赤い長方形・青い平行四辺形のスライダー入力）も利用できます。

## 起動

実行場所: **リポジトリのルート**（この README があるディレクトリ）。Node.js は `20.19+` または `22.12+` を使用してください。

```sh
npm ci
npm run dev
```

ターミナルに表示されたローカル URL をブラウザで開きます。WebGPU の検証には GPU を利用できるブラウザと、localhost または HTTPS が必要です。WebGPU を利用できなければ Three.js が WebGL 2 を試します。両方使えない場合はエラーを表示します。

## 検証

すべて **リポジトリのルート**で実行します。

```sh
npm test
npm run build
npm run preview
```

テストは Node.js 標準のテストランナーで実行し、追加のテストライブラリは使用していません。Lint は未設定です。

Phase 1 の画面では「2個に減らす」→「10個に戻す」で白い図形の復元を確認し、配置方式を Grid に変更してタイル配置を確認できます。Modifier、個別設定、グループ変換、Shape / Group の表示と前後関係も変更できます。図形数の上限は1グループ・全体とも1000個です。配置の間隔は中心間のステップです。

幅・高さ・傾斜、配置の間隔・位置・オフセット、グループの回転・倍率はスライダーで調整できます。併設の数値入力で細かい値を指定でき、通常のスライダー範囲を超える有効値を入力すると範囲も広がります。個数・行数・列数は数値入力、色はHEX入力です。

「プレビューを停止」で描画コンポーネントをアンマウントし、「プレビューを開始」で再初期化できます。入力は保存されません。サンプル画面の切り替えでは入力が初期化されます。
