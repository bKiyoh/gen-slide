# Generative Slide System

Vue 3 + Three.js の図形描画基盤。現在は **Phase 0** のみ実装しています。

赤い長方形と青い平行四辺形を描画し、幅・高さ・傾斜・中心位置・回転・色・不透明度を入力から変更できます。表示中の描画バックエンドと初期化エラーも画面に表示します。

## 起動

実行場所: **リポジトリのルート**（この README があるディレクトリ）。Node.js は `20.19+` または `22.12+` を使用してください。

```sh
npm ci
npm run dev
```

ターミナルに表示されたローカル URL をブラウザで開きます。WebGPU の検証には GPU を利用できるブラウザと、localhost または HTTPS が必要です。WebGPU を利用できなければ Three.js が WebGL 2 を試します。両方使えない場合はエラーを表示します。

## 検証

すべて **リポジトリのルート**で実行します。

```sh
npm test
npm run build
npm run preview
```

テストは Node.js 標準のテストランナーで実行し、追加のテストライブラリは使用していません。Lint は未設定です。

画面ではスライダーを動かして即時更新を確認できます。併設した数値入力で細かい値を指定することもできます。幅・高さ・位置のスライダーは通常1920×1080の範囲を使い、数値入力で範囲外の有効値を指定するとその値まで広がります。「プレビューを停止」で描画コンポーネントをアンマウントし、「プレビューを開始」で再初期化できます。入力は保存されません。

処理フロー、ファイル一覧、動作確認手順、受け入れ結果、制約は [Phase 0 実装・検証記録](docs/phases/phase-0-result.md) を参照してください。全体設計は [DESIGN](docs/DESIGN.md)、要件は [SPECIFICATION](docs/SPECIFICATION.md) にあります。
