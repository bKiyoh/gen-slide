# Generative Slide System

Vue 3 + Three.js の図形生成・制作ツール。現在は **Phase 5** まで実装しています。

初期画面は演出エディターです。左でレイヤーを選び、中央の「見た目を編集／動きを編集」で値を変更し、右上の小型プレビューで確認し、下のタイムラインで時刻を調整します。1366×768以上の通常表示ではページをスクロールせず操作でき、項目が多い場合は各一覧の中をスクロールします。4領域で、図形生成、個別設定、キーフレーム、再生・シークを操作できます。確定したProjectは約500ms後にlocalStorageへ自動保存され、「ファイル」からJSONの出力・検証付き読み込みにも対応します。JSON読込は既存の演出・スライドを残して末尾へ追加し、IDが衝突した場合は参照を保って自動調整します。「このJSONを追加」で確定し、追加全体を「元に戻す」で取り消せます。保存状態とエラーは画面上部に表示します。

「発表する」でProjectのスライドを再生します。「スライドに割当」で登録済みVueスライドの順序と、各ページから次へ進む演出を設定できます。初回は3枚・2種類の演出を用意しています。内容・演出を変更するとEditorのプレビューも連動します。各行の「プレビュー」で選び直し、「演出のみ」で通常の演出編集へ戻れます。保存済みProjectにスライドがない場合は「発表サンプルを追加」で既存の作品を残して試せます。Editorでの修正は次の発表開始時に反映されます。

発表中は右矢印・Space・PageDownで次、左矢印・PageUpで前へ移動します。戻る操作は即時切替、演出中の追加操作は無視します。全画面の開始・終了と操作パネルの非表示にも対応します。図形が全画面を覆わなくても演出を再生し、指定した切替時刻に次へ進みます。単色の幕（cover）の設定は不要です。描画エラー時は即時切替で発表を続けられます。

プレビューの図形をクリックし、ドラッグで移動、選択枠の四隅で一様拡縮、丸で回転できます。プレビュー見出しの選択欄で個別の図形とグループ全体を切り替えます。「拡大」でプレビューを広げられます。キー編集では対応するキーを明示的に選んでから操作し、位置・倍率は同時刻のX/Yキーを対にします。タイムラインのキーは1ms刻みでドラッグでき、隣のキーを追い越しません。再生ヘッドのドラッグはシークだけです。

「元に戻す」「やり直す」とCtrl/Cmd+Z・Ctrl/Cmd+Shift+Zを使えます。ドラッグ一回を履歴一件にまとめ、Escで操作を取り消します。履歴は最大50件・容量上限付きで、再読込・Editor再起動・保存データ再取得でリセットします。JSON追加では取り込み前の履歴を保持します。詳細は [Phase 5 実装・検証記録](docs/phases/phase-5-result.md) にあります。

「素材から追加」で開く意匠ライブラリに、斜線スイープ・センターブロック・チェッカー・フリップ・交互シャッター・フレームズームの5種類を用意しています。「追加して再生」で作品に追加して編集でき、「5パターンを発表で比較」で作業中のProjectを保ったまま見比べられます。比較用JSONはライブラリから保存するか、[配布ファイル](public/examples/design-patterns.json)を利用してください。

Phase 2 の画面では、時刻スライダーで0〜1200 msを指定し、時間差のある移動・回転とGroup全体の移動を確認できます。白い3番目の図形は独自の回転を持ちます。時刻を前後に動かしても同じ状態を再現します。確認用の時刻指定画面で、自動再生は後続Phaseの対象です。

個別 Shape と ShapeGroup を混在させ、Linear / Grid 配置、Alternate / Linear Modifier、個別 Overrides を確認できます。赤・青の平行四辺形10個のうち3番目だけ白・X +40にし、生成数を減らして戻しても上書きを保持します。表示中の描画バックエンドと初期化エラーも画面に表示します。

「使い方」の「開発用サンプル」から、従来の **Phase 1 · 図形の生成** と **Phase 0 · 描画基盤**（赤い長方形・青い平行四辺形のスライダー入力）も利用できます。

## 起動

実行場所: **リポジトリのルート**（この README があるディレクトリ）。Node.js は `20.19+` または `22.12+` を使用してください。

```sh
npm ci
npm run dev
```

ターミナルに表示されたローカル URL をブラウザで開きます。WebGPU の検証には GPU を利用できるブラウザと、localhost または HTTPS が必要です。WebGPU を利用できなければ Three.js が WebGL 2 を試します。両方使えない場合はエラーを表示します。

## 検証

すべて **リポジトリのルート**で実行します。

```sh
npm test
npm run build
npm run preview
```

テストは Node.js 標準のテストランナーで実行し、追加のテストライブラリは使用していません。Lint は未設定です。

Phase 2 の画面では開始・中間・終了のボタン、時刻スライダーと数値入力で表示を変更できます。「1個ごとの遅延」は初期値40 msです。0にするとChildの時間差がなくなります。Individualの回転は全体時刻を使うため、時間差を変更しても同じ時刻なら同じ角度です。「指定時刻の評価結果を見る」で値を確認できます。

Phase 1 の画面では「2個に減らす」→「10個に戻す」で白い図形の復元を確認し、配置方式を Grid に変更してタイル配置を確認できます。Modifier、個別設定、グループ変換、Shape / Group の表示と前後関係も変更できます。図形数の上限は1グループ・全体とも1000個です。配置の間隔は中心間のステップです。

幅・高さ・傾斜、配置の間隔・位置・オフセット、グループの回転・倍率はスライダーで調整できます。併設の数値入力で細かい値を指定でき、通常のスライダー範囲を超える有効値を入力すると範囲も広がります。個数・行数・列数は数値入力、色はHEX入力です。

Editorでは「使い方」の「GPU描画を停止」で描画コンポーネントをアンマウントし、「GPU描画を再開」で再初期化できます。Phase 0〜2では「プレビューを停止／開始」を使います。EditorのProjectは自動保存されます。Phase 0〜2の検証サンプルの入力は保存されず、サンプル画面の切り替えで初期化されます。

Presentationの状態遷移・切替・オフライン検証は [Phase 4 実装・検証記録](docs/phases/phase-4-result.md) を参照してください。本番ビルドをネット接続なしで使う場合は、事前にビルドした `dist` をローカルHTTPサーバーで配信します。**リポジトリのルート**で `npm run preview` を実行して表示されたURLを開けます。外部フォント・画像・CDNは不要です。初回配信前にHTMLへアクセスできない状況での起動は対象外です（Service Workerは導入していません）。
