このレポートについて

docs/phases/phase-*-result.md を原本として生成したHTML版です。本文はすべてこのファイルに含まれ、インターネット接続や開発サーバーなしで閲覧できます。Markdown原本・README・公式資料へのリンクは、移動先のファイルまたは通信が必要です。

実画面の画像は同じフォルダーの ui-ux-editor.png を参照します。画像も一緒に保管してください。

更新する場合はMarkdown原本を編集し、リポジトリのルートで npm run docs:report を実行してください。

「印刷 / PDF保存」で全Phaseをまとめて印刷できます。ブラウザのページ内検索で、ファイル名・API名・検証項目を探せます。
